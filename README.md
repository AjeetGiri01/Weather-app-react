# 🌦️ Weather App

A modern and responsive Weather Application built using **React.js** that allows users to check real-time weather information for different cities around the world.

The application provides essential weather details such as temperature, minimum and maximum temperature, feels-like temperature, and humidity with a beautiful gradient UI and weather-based background images.

## 🚀 Live Demo

🔗 **Live Website:** [https://weather-app-react-s5d6.onrender.com]

## ✨ Features

- 🌍 **Search Weather:** Search for weather information by entering any city name.
- 🌡️ **Real-Time Temperature:** Get the current temperature of a searched city.
- ❄️ **Minimum & Maximum Temperature:** Check the minimum and maximum temperatures.
- 💧 **Humidity Information:** View the current humidity level.
- 🌤️ **Weather Conditions:** Display weather conditions with suitable icons.
- 🎨 **Modern UI:** Attractive gradient backgrounds and beautiful card designs.
- 🖼️ **Dynamic Background Images:** Different background images based on weather conditions.
- 📱 **Responsive Design:** User-friendly interface with a clean layout.
- ⚡ **Error Handling:** Handles invalid city names and unsuccessful searches.

## 🛠️ Technologies Used

| Technology | Purpose |

## 🎨 UI Design

The application uses a modern design approach featuring:

- Deep ocean blue gradient background.
- Cyan and purple background glow effects.
- Glass-inspired search input.
- Gradient search button with hover animation.
- Light blue gradient weather card.
- Smooth transitions and rounded corners.
